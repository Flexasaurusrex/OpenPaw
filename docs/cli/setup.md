# `openpaw setup`

Initialize `~/.openpaw/openpaw.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
openpaw setup
openpaw setup --workspace ~/.openpaw/workspace
```

To run the wizard via setup:

```bash
openpaw setup --wizard
```
